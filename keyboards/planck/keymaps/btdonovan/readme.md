### 2025-05-16
Removed the Alt/GUI Swap functions because I kept triggering them and not knowing how to change back.

Removed No GUI/Yes GUI functions for the same reasons.

Swaped `(` with `{` and `)` with `}` on the CODE layer to match ordering on the raise layer.
